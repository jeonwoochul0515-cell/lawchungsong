## 규제 체크 (발행 전 반드시 확인)

- **승소·성공 보장, 최고, 1위, 전문(변협 미등록 분야)** 표현 금지.
- **우리 사무소의 상담료·수임료를 무료나 할인으로 표방하지 마세요.** 변협 광고규정 위반입니다. 원고에 나오는 "무료"는 전부 **국가가 운영하는 채무자대리인 무료지원 제도**를 가리키는 것으로, 사실 안내이므로 문제없습니다.
- **"원금 안 갚아도 된다"는 단정 금지.** 무효 요건에 해당하는지는 사안마다 다르고 최종 판단은 법원이 합니다. 원고는 모두 조건부 서술로 썼으니 수정하실 때도 이 톤을 유지해 주세요.
- 근거 법령을 본문에 남겨두시면 신뢰도에 도움이 됩니다.
