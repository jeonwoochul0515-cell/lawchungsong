## 발행 대기 (위에서부터 순서대로)

- [ ] **공증 받은 차용증은 뭐가 다른가 — 소송 없이 바로 압류하는 집행증서** — 타깃 키워드: 차용증공증, 공정증서. 요지: 금전소비대차 공정증서·약속어음 공증의 집행력, 공증 비용과 준비물, 공증이 만능이 아닌 경우(청구이의). 받아드림 소개 1회.
- [ ] **채무자가 재산을 숨겼는지 확인하는 법 — 재산명시·재산조회·채무불이행자명부** — 타깃 키워드: 재산명시신청(2,430), 채무불이행자명부(660). 요지: 판결 후에도 재산을 모를 때 쓰는 세 가지 카드의 순서와 각각의 한계, 명시선서 거부·허위목록의 제재(감치·형사), 명부 등재가 실제로 압박이 되는 이유(신용정보 통보). 받아드림 소개 1회.
- [ ] **소송 전에 재산을 먼저 묶는다 — 가압류와 담보공탁의 현실** — 타깃 키워드: 가압류신청(610). 요지: 가압류가 필요한 국면(재산 처분 징후), 담보공탁금 비율과 현금공탁·보증보험의 차이, 본안 패소 시 손해배상 위험, 가압류만 걸어두고 본안을 놓치는 실수(제소명령). 받아드림 소개 1회.
- [ ] **집행관과 채무자 집에 들어가는 날 — 유체동산 압류의 실제** — 타깃 키워드: 유체동산압류(1,140). 요지: 압류 신청부터 현장 집행까지의 절차, 압류금지 물건(민사집행법 §195)과 실제로 남는 것, 경매 환가율이 낮은 이유, 그럼에도 압류가 협상 카드가 되는 국면. 받아드림 소개 1회.
- [ ] **지급명령에 이의가 들어왔다 — 소송으로 넘어간 다음의 순서** — 타깃 키워드: 지급명령이의신청(2,520). 요지: 이의신청 기간(2주)과 효력(소 제기 간주), 인지대·송달료 추가 납부, 조정 회부 가능성, 처음부터 소장을 내는 편이 빠른 사건의 구분. 받아드림 소개 1회.
