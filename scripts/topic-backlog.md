# 주간 칼럼 주제 백로그 (자동 발행 루틴용)

> 매주 월요일 자동 발행 루틴이 이 목록의 **가장 위에 있는 미완료(`[ ]`) 주제 1개**를 골라 칼럼을 쓰고, 완료 표시(`[x]` + 발행일)를 한 뒤 커밋한다.
> 주제는 2026-07-17 네이버 API 리서치(검색량·경쟁도·검색결과 갭 실측)로 선정됨. 가맹본부 B2B 시리즈와 부산 로컬 니치를 번갈아 발행한다.
> 백로그가 3개 이하로 줄면 루틴이 발행 후 보고에 "백로그 보충 필요"를 남긴다.

## 발행 대기 (위에서부터 순서대로)

- [ ] **[B2B ④] "평균 매출 이 정도 나옵니다"가 소송이 되는 순간 — 허위·과장 정보제공 금지** — 카테고리: 가맹·프랜차이즈. 타깃 키워드: 가맹사업법위반, 가맹금반환. 요지: 가맹사업법상 허위·과장 정보제공 금지, 예상매출액 산정서 의무, 위반 시 가맹금 반환·손해배상, 본부가 지켜야 할 화법.
- [ ] **[부산니치] 부산가정법원 소년재판 — 소년위탁보호위원이 설명하는 보호처분의 실제** — 카테고리: 학교폭력·소년보호. 타깃 키워드: 소년재판(3,400), 소년보호처분(3,130), 부산 소년재판. 요지: 소년보호재판 절차, 1~10호 보호처분, 위탁보호위원 제도(김창희 = 부산가정법원 소년위탁보호위원), 보호자가 준비할 것.
- [ ] **[B2B ⑤] 가맹점주와 분쟁이 생겼을 때 — 가맹사업거래분쟁조정협의회 조정 절차** — 카테고리: 가맹·프랜차이즈. 타깃 키워드: 가맹분쟁조정(70원 광고 키워드), 가맹점분쟁. 요지: 공정거래조정원 분쟁조정 절차, 조정의 효력, 본부·점주 각각의 대응 전략.
- [ ] **[부산니치] 부산에서 무료 법률상담 받을 수 있는 곳 총정리 — 그리고 변호사 상담이 꼭 필요한 순간** — 카테고리: 형사. 타깃 키워드: 부산무료법률상담(530), 부산법률구조공단(900·경쟁 낮음). 요지: 법률구조공단 부산지부·구청 상담 등 공공 자원 안내(신뢰 콘텐츠), 무료 상담의 한계와 사선 변호사 상담이 필요한 경우. ※ 광고규정: 우리 상담을 '무료'로 표방하는 표현 금지.
